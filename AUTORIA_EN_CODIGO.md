# Convención de nombres PMMD

El sufijo PMMD se aplica a nombres Java propios. Las constantes renombradas utilizan _PMMD. Se mantienen los contratos de bibliotecas, el esquema SQLite, los valores persistidos, los enlaces FXML y los nombres de propiedades cuando no se ha podido verificar su refactorización. Las pruebas de ejecución requieren Maven y las dependencias del proyecto.
